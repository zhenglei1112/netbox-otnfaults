# blueglobe.js 深度研究：证据账本（内部）

研究日期：2026-08-30

## 范围与假设

- 受众：NetBox OTN 态势大屏的技术决策者与实现者。
- 决策：是否直接采用 blueglobe.js，以及哪些架构思想适合迁移至 dashboard-v2。
- 边界：仅分析官方文档、官方站点公开信息、依赖项目官方资料及浏览器可公开下载的构建产物；不还原、复制或重新发布专有源码。
- 时间：结论反映 2026-08-30 的公开状态，线上 bundle 哈希和体积会变化。

## 证据等级

- A：官方文字直接确认。
- B：官方服务器公开构建产物或响应元数据直接观察。
- C：由 A/B 证据和 WebGL 常规实现推导，报告必须显式标注为推断。

## 关键未决项

- 精确 shader 数量、每个 pass 的绘制顺序和状态切换策略。
- 标签遮挡/碰撞算法、文字 atlas 的具体组织。
- 对象拾取是否全部使用颜色 ID framebuffer，还是与 CPU 射线检测混合。
- 主线程与 Worker 间数据交换的精确数据结构、批次频率与所有权策略。
- 后端 API、数据库和数据清洗流水线的内部 schema。
