# 故障等级与事件汇总悬停效果设计

## 目标

增强“故障等级与事件汇总”彩色指标卡片的鼠标悬停反馈，使其视觉表现与左侧故障等级占比 ECharts 扇区的高亮效果一致：边界清晰、阴影明显，并保持当前布局与交互不变。

## 方案

保留现有 HTML/CSS 网格，不替换为 ECharts。仅调整 `.impact-level-block-item` 的交互样式：

- 使用白色 `2px` 内描边，避免边框改变元素尺寸或引发布局抖动。
- 悬停时轻微上移并约放大至 `1.03` 倍，突出当前指标块。
- 增强阴影，模拟 ECharts `emphasis.itemStyle` 的浮起效果。
- 移除透明度降低，确保色块和文字在高亮时仍然鲜明。
- 为键盘聚焦提供相同高亮效果，并保留清晰的焦点可见性。
- 提升高亮项的层级，防止阴影或放大部分被相邻色块遮挡。

## 保持不变

- 两列四行布局、总次数跨两列布局及卡片高度。
- 各等级颜色、文字、趋势差值及其颜色。
- 指标下钻、割接实施点击行为和数据加载逻辑。
- 左侧三个 ECharts 环形图配置。

## 验证

- 添加静态回归测试，验证汇总卡片包含白色内描边、放大、明显阴影、层级提升及键盘聚焦规则。
- 运行该回归测试和现有故障等级统计测试。
- 检查模板静态资源版本，确保浏览器不会继续使用旧样式缓存。
