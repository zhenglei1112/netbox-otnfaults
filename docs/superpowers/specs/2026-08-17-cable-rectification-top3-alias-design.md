# 原因 TOP3 光缆整改展示别名设计

## 目标

在故障统计物理故障页的“原因TOP3”、“原因TOP3历时”和“主要原因”图中，将分类“光缆整改”的界面名称显示为“光缆整改未报备”。

## 范围

- 修改上述两个物理故障卡片以及“主要原因”图图例和悬浮提示中的显示名称。
- 不修改分公司区域、其他图表、后端统计数据或数据库分类值。
- 其他原因名称保持不变。

## 数据与交互

- 原始 `name` 保持“光缆整改”，用于当前值与环比、同比数据匹配。
- 为需要改名的当前 TOP3 项增加 `displayName: '光缆整改未报备'`。
- 卡片标签和明细弹窗筛选名称使用 `displayName`。
- 下钻请求的 `filterValue` 仍使用原始 `name`，即传递 `reason=光缆整改`。
- “主要原因”图的 ECharts 数据项 `name` 保持“光缆整改”，图例格式化和悬浮提示使用统一展示名函数，因此点击扇区与图例排除仍使用原始名称。
- “主要原因”图的“中断数量”和“中断时长”两种模式均应用展示别名。
- 当前后端已排除报备割接，因此该原始分类在这两个卡片中的剩余数据即为未报备光缆整改。

## 实现

增加统一的原因展示名函数，把“光缆整改”转换为“光缆整改未报备”。扩展共用 `buildFlexGroup()`：数据匹配和默认筛选值继续使用原始 `name`，展示标签与默认筛选文案优先使用可选的 `displayName`。两个原因 TOP3 当前列表通过该函数设置 `displayName`；“主要原因”图的图例和提示框直接调用同一函数，同时保留 ECharts 数据项原始名称。提升统计脚本查询版本，确保浏览器加载新代码。

## 验证

增加源码级前端回归测试，确认：

- 只有原始名称为“光缆整改”的项获得“光缆整改未报备”展示名。
- 两个指定 TOP3 当前列表都应用别名函数。
- `buildFlexGroup()` 仍用原始名称匹配环比和同比。
- 下钻筛选值仍为原始名称，弹窗筛选名称使用展示名。
- 分公司 TOP3 渲染不应用该别名。
- “主要原因”图的数据项保留原始名称，图例与提示框使用展示名。
- 图例排除和扇区点击下钻继续使用原始名称。
