# 故障统计可见指标说明分 Tab 设计

## 背景

故障统计页的“指标说明”弹窗目前按历史统计主题集中展示，包含已经隐藏或不再由前端渲染的内容，例如隐藏的总体情况、I 类和 II 类汇总卡片，以及后台仍计算但前端已不展示的子公司评分、评级和扣分规则。同时，部分说明未同步近期统计范围调整。

本次只调整前端指标说明，使说明内容与当前页面实际可见内容一致，不改变任何统计计算、接口字段、页面指标或图表行为。

## 目标

- 指标说明覆盖故障统计页面全部可见 Tab。
- 打开说明弹窗时，默认定位到当前正在查看的主页面 Tab 对应说明。
- 用户可以在说明弹窗内手动切换并查看其他页面的说明。
- 弹窗内的说明 Tab 不切换底层统计页面。
- 每次重新打开弹窗时，重新同步当前主页面 Tab，不保留上一次手动切换位置。
- 删除未在前端展示的指标说明，并修正可见指标中已经确认的口径偏差。

## 信息架构

指标说明弹窗内部使用与主页面顺序一致的 5 个说明 Tab：

1. 物理故障
2. 裸纤业务故障
3. 电路业务故障
4. 子公司（省份）故障
5. 子公司绩效

每个说明 Tab 只描述对应主页面中当前可见的卡片、图表、筛选、日历和下钻交互。

## 交互设计

### 打开弹窗

监听指标说明弹窗的 Bootstrap `show.bs.modal` 事件，读取主页面导航中当前带有 `active` 状态的 Tab，并通过固定映射激活对应的说明 Tab。

主页面与说明页映射如下：

| 主页面 Tab | 说明 Tab |
| --- | --- |
| `tab-physical-btn` | 物理故障 |
| `tab-service-btn` | 裸纤业务故障 |
| `tab-circuit-service-btn` | 电路业务故障 |
| `tab-branch-company-btn` | 子公司（省份）故障 |
| `tab-branch-performance-btn` | 子公司绩效 |

找不到当前主页面 Tab 时，回退到“物理故障”说明。

### 弹窗内切换

说明导航使用 Bootstrap 5 原生 Tab 结构。用户手动切换说明 Tab 时，只改变弹窗内容，不触发主页面 Tab、筛选条件或数据请求。

### 再次打开

关闭弹窗后无需持久化内部选择。下次打开时重新根据当前主页面 Tab 激活对应说明。

## 说明内容范围

### 物理故障

说明当前可见的裸纤业务中断概览、故障和异常事件等级、光缆中断指标、环形图、原因/资源/省份/历时图、箱线图以及故障明细下钻。

删除或修正：

- 删除隐藏“总体情况”区域专属说明。
- 删除前端隐藏的“I 类和 II 类”独立指标说明。
- 明确等级统计和光缆中断统计排除计划报备整改；光缆中断同时排除挂起。
- 箱线图第五项按实际实现描述为上须阈值，而不是最大值；异常点单独展示。
- 挂起历史总数说明为当前省份筛选范围内的历史总数；未选择省份时才是全系统范围。
- 保留有效历时、长时、P50/P90、超时率、日夜时段、资源归组和重复故障规则。

### 裸纤业务故障

说明业务卡片的年度累计、本期间分类汇总、运行月历、中断日历、故障业务/全部业务切换和明细下钻。

明确本期间与年度/月历当前实际采用的挂起过滤差异，不用统一口径文案掩盖现状；年度 SLA 只按当前实现描述，不承诺未实现的跨年度边界裁剪。

### 电路业务故障

说明与电路业务 Tab 实际展示一致的年度累计、本期间分类汇总、运行月历、中断日历和明细下钻。明确仅统计业务影响为“中断”的电路影响记录，不限定物理故障类型为光缆中断。

### 子公司（省份）故障

说明六省范围、维护单位排除规则、裸纤业务中断、光缆中断指标、故障数/历时图、箱线图、有效平均历时、周/月趋势、千公里切换和明细下钻。

### 子公司绩效

只说明当前卡片实际渲染的内容：

- 年度裸纤业务统计；
- 年度未挂起光缆中断统计；
- 年度供电故障统计；
- 运行月历；
- 中断日历；
- 千公里/原始值切换。

删除责任得分、全量得分、评级、扣分项、责任权重等后台保留但前端未渲染的说明。

- 仅在确有需要时调整 `statistics_dashboard.css`，保持 NetBox Bootstrap 5 原生样式优先。

- 更新静态资源版本号，确保新增脚本或样式及时生效。

## 测试与验收

- 测试锁定 5 个说明 Tab 及其顺序。
- 测试锁定主页面与说明页映射以及 `show.bs.modal` 同步入口。
- 测试确认弹窗内说明 Tab 不触发主页面切换或数据加载。
- 测试确认已隐藏的评分、评级、扣分和 I+II 独立卡片说明不再出现。
- 测试确认计划报备排除、箱线图上须和挂起范围等修正文案存在。
- 运行故障统计说明弹窗相关测试和 JavaScript 语法检查。

## 非目标

- 不修改后端统计逻辑或 API 响应。
- 不恢复子公司评分展示。
- 不修复本次审计发现的评分布尔字段、业务挂起口径或 SLA 边界问题。
- 不让说明弹窗驱动主页面 Tab 切换。
- 不保存用户上一次选择的说明 Tab。
