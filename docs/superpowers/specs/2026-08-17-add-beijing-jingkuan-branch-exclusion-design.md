# 子公司统计增加北京京宽排除项设计

## 目标

将代维方/租赁方“北京京宽网络科技有限公司”对应的故障排除在子公司统计之外。

## 实现

- 在 `statistics_views.py` 的统一集合 `EXCLUDED_HANDLING_UNITS` 中增加公司全称。
- 保持现有精确名称匹配规则不变，不依赖不同环境可能变化的服务商数据库 ID。
- 现有 `_is_branch_company_fault()` 调用链不变，因此该排除项同时作用于子公司汇总、绩效、当前周期明细及前序重复故障明细。

## 测试

- 先在 `tests/test_statistics_branch_company.py` 的排除名单回归测试中增加新公司断言并确认失败。
- 再增加生产配置项并确认定向测试通过。
- 最后运行相关测试与 Python 编译检查。

## 非目标

- 不修改服务商数据。
- 不改为按服务商 ID 排除。
- 不引入数据库可配置排除名单。
