# 今明割接通报结构化提示设计

## 目标

将“今日明日割接”小组件中 9 点、18 点通报的提示正文调整为截图所示的结构化格式，同时保持现有业务分组、筛选时间窗和复制功能不变。

## 输出格式

完整通报首行显示“24小时割接预告（开始时间 至 结束时间）”。每个业务分组内的割接条目按当前顺序编号，编号在每个分组内从 1 开始：

```text
（1）河北省（华为京汉产业务）
    割接类型：光缆割接
    计划时间：2026年8月5日 0:00，预计时长120分钟
    中继段：A端南淳收费站（入口方向），Z端湖州北
    割接地点：南京市鼓楼区中央北路77号
    割接原因：市政施工，线路迁改
```

动态字段清除换行、制表符及多余空白。计划时间的小时不补前导零，分钟固定为两位。

## 数据映射

- 省份、割接类型、计划时间、预计时长、割接地点、割接原因来自当前割接任务。
- 业务名称来自当前影响业务；未关联时使用“未关联业务”。
- 中继段继续使用当前影响业务 A/Z 端站点，缺失时回退到割接任务 A/Z 端站点。

## 保持不变

- 裸纤按租户组分组；无租户组、纯电路业务和未关联业务沿用现有分组名称。
- 待实施状态过滤、9 点/18 点未来 24 小时半开时间窗和排序不变。
- 每个业务影响仍生成一条通报；同一割接的分组数量仍按割接主键去重。
- 弹窗继续按业务分组展示，保留“复制本组”和“复制全部”。

## 展示与复制

分组卡片标题不变；卡片正文改为组内编号条目。复制本组复制该组正文，复制全部复制时间窗标题以及所有业务分组标题和正文。无割接时继续输出当前无待实施割接提示。

## 测试

格式化器测试锁定结构化条目、字段清洗、中文日期时间和未关联业务；小组件测试锁定新增字段、完整报告标题和组内编号，同时保留现有业务分组断言。运行相关单元测试、Python 编译检查和 `git diff --check`。
