# 故障列表时间选择器中文化设计

## 目标

故障列表筛选页的所有 Flatpickr 时间选择器显示中文月份和星期，同时打开空筛选字段时不得自动写入当前时间。

## 设计

复用现有 `flatpickr_zh.html`。为其中“打开空字段时自动填入当前时间”的钩子增加模板开关 `disable_default_now`：现有编辑页不传该开关，行为保持不变；故障列表页以 `disable_default_now=True` 引入该模板，只应用中文 locale。

本次不修改日期格式、时区、快捷时间按钮或其他页面的时间字段行为。

## 测试

- 故障列表模板必须以禁用自动填时的方式加载中文 locale。
- 中文 locale 始终应用。
- 自动填时钩子仅在未禁用时注册。
- 现有编辑页继续使用默认行为。
