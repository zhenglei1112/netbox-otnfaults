# 故障统计标题筛选口径标签设计

## 目标

将故障统计“物理故障”页两个区域标题中的筛选口径说明，从普通标题文本改为独立的橙色标签，使标题名称与统计范围更容易区分。

## 展示规则

- “故障和异常事件（按影响程度划分等级）”标题后显示一个“`不含报备割接`”标签。
- “光缆中断情况”标题后依次显示“`不含报备割接`”和“`不含挂起`”两个标签。
- 每个筛选条件使用独立标签，不合并为一个标签。
- 标签继续使用 NetBox 已有 Bootstrap 5 样式 `badge bg-warning text-dark`，并增加专用类 `statistics-scope-badge`，避免影响页面内其他徽章。
- `statistics-scope-badge` 的字号为 `0.75rem`，行高为 `1`，内边距为上下 `0.2rem`、左右 `0.45rem`；保留 Bootstrap 的橙色、深色文字和圆角。
- 保持“定位地图”按钮的现有位置、样式和行为。

## 实现范围

调整 `statistics_dashboard.html` 中上述三个标签的类名，并在 `statistics_dashboard.css` 中增加局部尺寸规则；同步提升样式表查询版本，确保浏览器加载新样式。不修改后端查询、统计口径、接口、JavaScript 或其他页面标题及徽章。

## 验证

增加源码级模板回归测试，确认：

- 两个区域保留原有主标题。
- 第一处恰好包含所需的“`不含报备割接`”标签。
- 第二处分别包含“`不含报备割接`”和“`不含挂起`”标签。
- 原来的连字符普通文本形式不再出现。
- “定位地图”按钮仍位于光缆中断标题区域。
- 三个标签都使用 `statistics-scope-badge`，且该类具有约定的字号、行高和内边距。
