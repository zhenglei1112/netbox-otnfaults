# Dashboard V2 star catalogue

`dashboard_v2_hyg_bright_stars.json` is a derived, magnitude-limited subset of
HYG Database v4.1. Each row contains `[right ascension hours, declination
degrees, apparent magnitude, B-V color index]`. The subset includes non-solar
entries with apparent magnitude less than or equal to 6.5.

Source: David Nash / Astronomy Nexus, HYG Database v4.1:
https://github.com/astronexus/HYG-Database/tree/main/hyg/CURRENT
